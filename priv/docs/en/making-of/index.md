Mercator was first written in Ruby on Rails with Hobo, between 2013 and 2017. This version is a port to Elixir, Phoenix and Ash, made by one developer working with an AI coding assistant, Claude Code.

The sessions below are the actual conversations from the port, from the first look at the old repositories to the deployment of this demo. Only the conversation is kept: thinking, tool calls and tool output are left out, and personal details (names, addresses, infrastructure) are replaced.

The **metrics** show the size of the result and how long it took.

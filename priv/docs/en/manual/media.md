**Content → Media** holds the images and PDFs for pages and advice.

- **Uploading:** drop several files onto the area at once. Each file needs at least one tag; existing tags are suggested. Images are stored in several sizes.
- **Finding:** by text, tag and kind (image or PDF).
- **Editing:** clicking a file shows its title, alt text (for screen readers and search engines) and tags, plus a ready-made Markdown snippet to put the image or PDF link into any text.
- **Deleting:** only files no page uses.

The image blocks of a page and sharing at the sales desk pick files straight from the media library.

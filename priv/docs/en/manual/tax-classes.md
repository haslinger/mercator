**Administration → Tax classes** sets the VAT rates products carry, e.g. 20 % (standard) and 13 % (reduced, e.g. for firewood).

The list shows each class with its rate and number of products. Name and rate can be changed; only classes no product uses can be deleted. Existing orders keep the VAT they were placed with.

# Biber Holz brand sources

Original artwork of the demo brand Biber Holz, kept as source material. The
app does not serve these files; the files it serves are derived from them in
`priv/static/images/brands/biberholz/`:

| Source | Derived |
|---|---|
| `logo.jpeg` (1408×768, checkerboard "transparency" baked into the pixels) | `logo.webp` (512×512, medallion cut out with real transparency), `logo-256.png` (for emails) |
| `biber-pin.png` | `pin.webp` |
| `favicon.svg` | `favicon.svg` (copy), `apple-touch-icon.png` (180×180) |
